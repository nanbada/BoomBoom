- 제작: 원장님 1인. 채널은 학원과 별개로 개인이 운영한다.
- 발행량: 주 3회 업로드 = 새 본편 1편 + 쇼츠 2편(원장님 확정).
- 주간 가용 시간: 30~50시간(주말 포함). 지속 가능성은 3단계에서 실제 작업 시간으로 판정한다.
- 예산: 무료 도구 우선. 필요한 도구는 GitHub 오픈소스와 Claude·GPT·Gemini 유료 멤버십으로 직접 개발한다. 유료 결제는 Gemini API(TTS)와 Fish Audio API(Drama 3) 종량제를 음성용으로 쓰고, ElevenLabs Starter는 차선으로 남긴다. 그 밖의 유료 도구와 API 과금은 건별로 원장님 확인을 받는다.
- 수익: 시즌 1은 광고 수익 없이 버틸 수 있는 시간·현금 규모로 운영한다(9절).
- 채널은 공개 전이다.

## 1. 시즌 1 대상: 5~7세, 영어 입문(Pre-A1)

5~7세 트랙으로 확정한다. Gemini 벤치마크 표(원장님 확인: Gemini 최신 모델 조사, 신뢰도 높음)에서 규모가 가장 큰 채널(Pinkfong, BabyBus, Peppa Pig)은 모두 7세 이하를 겨냥한다. Tubefilter의 2025년 11월 주간 조회수 상위 50개 채널 가운데 아동 채널로 보이는 7개도 모두 미취학 아동용 스타일이다. 8~10세 대상 채널 중 큰 편인 Peekaboo Kidz(Dr. Binocs)는 2026년 10월 기준 약 787만 명으로, 미취학 대상 상위 채널과 규모 차이가 크다.

공개 후 우리 채널 데이터로 시청자 나이를 직접 확인하기는 어렵다. YouTube는 아동용 콘텐츠의 시청자 데이터를 제한할 수 있다고 안내한다. 보조 근거가 더 필요해지면 0~2단계 동안 비교 채널들의 새 업로드 D+7 조회수를 매일 기록한다(선택).

언어·연출 기준:

- 편마다 핵심 목표 1개, 보조 표현은 없거나 1개(10절 표의 '—'는 없음). 반대말 한 쌍(hot/cold)은 목표 1개로 센다. 문장은 2~5단어로 하되 "Pull!"처럼 10절에 정한 한 단어 명령은 그대로 쓴다.
- 어휘는 Cambridge Pre A1 Starters 단어 목록과 대조한다. 목록 밖 단어는 화면으로 뜻이 확실히 보일 때만 쓴다.
- 유머는 몸 개그, 크기·색 변신, 엉뚱한 음식 조합.

8~10세 미스터리 트랙은 시즌 2 후보로 보류한다.

## 2. 채널 한 줄 정의와 워치 규칙

"영어로 말하면, 그대로 이루어진다."

모모가 사고를 치면 토비의 워드팝 워치로 고친다. 노래 중심(Pinkfong), 원어민용 생활 이야기(Peppa Pig, Bluey), 교과서형 상황극(English Singsing)과 달리 매회 '말 → 결과'의 인과를 보여준다.

워치 규칙은 편마다 흔들리지 않게 고정한다.

- 워치는 명령문에만 반응하고, 말한 그대로 실행한다. 질문·감탄·묘사 문장은 캐릭터 행동과 화면으로 보여준다. 워치를 쓰지 않는 편도 있다(10절).
- 벌칙(바나나 파이)은 모모가 뜻이 다른 엉뚱한 단어를 골랐을 때만 나오는 상황 개그다. 발음·억양 실수에는 벌칙이 없다.
- 시청자 참여는 말하기·속삭이기·가리키기 중 고르게 한다. 외침을 요구하지 않는다. 영상이 아이 목소리를 실제로 듣는 것처럼 보이는 연출(마이크 아이콘, 반응하는 음량계)은 쓰지 않는다.
- 본편은 문제를 해결하고 끝난다. 다음 화 예고는 주제를 짧게 보여주는 정도이며 위협이나 긴급 구조 요청 형태로 만들지 않는다.

## 3. 포맷

| 포맷 | 길이 | 구성 | 역할 |
|---|---|---|---|
| 본편 | 3:00~3:30 | 콜드 오픈(~10초) → 사고와 첫 시도 → 중간 챈트(20~25초) → 시청자 참여 → 해결 → 퀴즈 2문항 → 짧은 예고. 핵심 목표 노출 8~10회 | 시청 시간 |
| 쇼츠 | 30~45초 | 그 자체로 완결된 미니 에피소드. 매주 1편은 본편 장면을 세로로 다시 연출, 1편은 단독 개그 | 발견 |
| 합본 | 15~25분 | 본편 4~6편을 주제별 복습으로 묶고 편 사이에 연결 설명·퀴즈 | TV 시청, 시청 시간 누적 |

쇼츠가 본편으로 시청자를 넘겨줄 것이라고 가정하지 않는다. Studio 발췌 도구는 아동용 쇼츠에 원본 영상을 자동 연결하지 않는다. 쇼츠는 혼자서도 학습이 완결되게 만들고, 본편 유입은 따로 잰다.

검증은 공개 범위별로 나눈다. 화면·음성·아동용 설정은 3단계에서 비공개 업로드로 확인한다. 관련 동영상 연결은 대상이 공개 또는 일부 공개 영상이어야 하므로, 원장님이 승인하면 일부 공개 테스트로 가능한 범위를 확인한다. 일부 공개 영상도 링크를 받은 사람이 다시 퍼뜨릴 수 있다. 추천·채널 페이지 유입처럼 공개 상태에서만 확인되는 동작은 공개 직후 점검 항목으로 넘긴다.

Gemini안의 4분 30초를 3분대로 줄인 이유는 1인 제작량과 5~7세의 집중 시간이다. 시청 테스트와 공개 후 시청 지속률을 보고 늘릴 수 있다.

## 4. 캐릭터와 세계관

시즌 1 고정 출연은 토비(골든리트리버, 리더)와 모모(치즈 고양이, 사고뭉치) 두 명, 조연은 바나비(코알라) 한 명이다. 코코, 폭시 렉스, 인간 쌍둥이, 돌고래 피니는 시즌 2 이후로 미룬다. 세트는 탐정 트리하우스 HQ와 마을 광장 두 곳이다.

디자인은 2.5~3등신, 검은 실루엣만으로 구분되는 형태, 캐릭터당 3색, 입 주변 흰색을 지킨다.

캐릭터는 오래 쓸 IP다. AI가 만든 이미지는 사람의 창작 기여가 없으면 저작권 보호를 받기 어렵고, 단순 트레이싱이나 벡터 변환만으로는 기여가 충분하지 않다(미국 저작권청 2025년 보고서, 문화체육관광부 생성형 AI 저작권 안내서). AI 시안은 방향 참고로만 쓰고, 형태·표정·의상·동작은 원장님이 직접 설계해 SVG로 그린다. 스케치, 수정본, 날짜를 남긴다. 기존 작품 모방 지시("like Sheriff Labrador and Bluey")는 외형 명세에서 뺀다.

목소리: 토비·모모·바나비 세 명의 목소리를 원장님 계정에서 설계한다. 기준 엔진은 Gemini 3.8 Flash TTS와 Fish Drama 3, 차선은 ElevenLabs다(원장님 결정, 2026-10-21). 아이 음색과 어려 보이는 성인 음색을 1단계 파일럿에서 비교해 정한다. 캐릭터는 피치가 아닌 음색·속도·에너지로 구분하고, 억양은 표준 미국식으로 맞춘다. 설계한 목소리는 어디에도 공유하지 않으며, ID와 설계 프롬프트를 `05_Ops/voices.md`에 기록한다. 실존 아동의 목소리를 녹음·복제·모방하지 않는다. 가이드 녹음 → Speech-to-Speech 방식은 기준 엔진에 해당 기능이 없어 쓰지 않는다. 엔진별 확인 결과와 파일럿 기준은 `03_Voice_Decision.md`에 있다.

## 5. 제작 파이프라인 설계안

구현은 이 계획 승인 후 시작한다. 편마다 사람이 하는 일을 대본, 그림, 검수로 좁히고, 음성 생성·타이밍·립싱크·자막 팝업·글로우·퀴즈 타이머·가로/세로 렌더·음량 정규화는 코드가 맡는다.

```
script.yaml        장면·대사·동작·효과 지시 (사람이 작성, 스키마 검증)
  → 대사 목록      script.yaml에서 추출 (대사ID·캐릭터·텍스트·감정·장면)
  → 음성           Gemini 또는 Fish TTS, 발화 턴 단위 단일 화자 생성 → 검수·채택 테이크 기록
  → 타이밍         로컬 강제 정렬로 단어 타이밍 (Gemini는 타임스탬프를 주지 않음)
  → 립싱크         Rhubarb Lip Sync (캐릭터별 무배경 음성 + 대사 원문 입력)
  → 조립           Remotion(React): SVG 컷아웃 캐릭터 + 장면 프리셋
  → 렌더           같은 장면 데이터를 가로(16:9)·세로(9:16) 카메라로 각각 렌더
  → 음량           ffmpeg loudnorm (-14 LUFS, -1 dBTP)
  → 업로드         제목·설명·재생목록 템플릿 채워 수동 업로드
```

| 단계 | 도구 | 비용 | 조건·메모 |
|---|---|---|---|
| 대본 초안 | Claude, GPT, Gemini 채팅 | 보유 멤버십 | 파이프라인은 LLM API를 호출하지 않는다. API 호출이 필요해지면 별도 과금이므로 승인 대상 |
| 캐릭터 | AI 시안(codex CLI) → 직접 SVG 작도(Inkscape) | 무료 | 레이어: 머리·몸·팔·다리·눈·입. 가려진 부위까지 직접 그린다 |
| 배경·소품 | codex CLI(차선 `agy`) 이미지, 영상 작업 전에 앵글·소품별로 전부 생성. 필요한 자산만 벡터화 | 보유 구독 | 아래 '이미지 생성' 참고 |
| 음성 | Gemini 3.8 Flash TTS, Fish Drama 3 | 종량제, 월 몇 달러 예상 | Gemini는 유료 티어만 쓴다(무료 티어는 입력이 제품 개선에 쓰임). 출력 오디오 100만 토큰당 9달러, 2027-01-01부터 18달러. Fish는 프리뷰이고 11/12까지 100만 자당 10달러, 이후 정가 50달러. Fish 약관은 이용자 콘텐츠를 모델 학습에 쓸 수 있게 한다. 두 엔진 모두 `03_Voice_Decision.md`의 '엔진 사용 전 확인'을 마친 뒤에만 호출한다. 서비스별 예산 알림 설정 |
| 음성(차선) | ElevenLabs Starter | 월 6달러 | 기준 엔진이 탈락할 때만 결제. 월 30,000크레딧, 상업 라이선스 포함. 무료 플랜·베타 산출물은 상업 이용 불가 |
| 강제 정렬 | 로컬 무료 도구(Montreal Forced Aligner, WhisperX 등) | 무료 | 1단계에서 최신 문서 확인 후 선정 |
| 효과음 | CC0 효과음 또는 직접 합성 | 무료 | 30종 정도를 한 번 만들어 재사용. 파일별 출처·라이선스 기록 |
| 챈트 반주 | 코드로 만든 120 BPM 패턴 + FluidSynth·사운드폰트 | 무료 | 사운드폰트 파일별 라이선스·표시 의무 기록. Eleven Music은 서비스별 약관 확인 후 선택 |
| 립싱크 | Rhubarb Lip Sync | 무료 | 기본 입모양 6종(A~F)으로 시작, 필요하면 G·H·X 추가 |
| 애니메이션 | Remotion | 무료 | 개인 운영이므로 무료 라이선스 대상. 나중에 직원 4명 이상 사업체로 운영 주체가 바뀌면 다시 검토 |
| 마스터링 | ffmpeg | 무료 | |

주당 대사량을 본편 1,500~2,000자, 쇼츠 2편 600자 정도로 잡고 재생성을 세 번씩 하면 월 3만 자 안팎이 된다. Fish 정가 50달러를 적용해도 월 2달러가 안 된다. Gemini는 오디오 토큰 단위로 과금하므로 1단계에서 Voice Design 미리듣기와 재시도를 포함한 실제 사용량을 재서 다시 계산한다. 대사는 대본을 확정한 뒤 생성해 재시도를 줄인다. 두 서비스 모두 자동 충전을 끄고 예산 알림을 건다.

### 이미지 생성

이야기는 Claude가 끌고 가고, GPT는 그리기만 한다(원장님 결정, 2026-10-22). Claude가 스토리보드와 컨셉을 가장 잘 알고 있으므로 연출, 스토리보드, 대본, 이미지 프롬프트를 모두 Claude가 설계한다. 이미지는 GPT(codex CLI)가 생성하고, Claude가 준 프롬프트를 고치지 않고 그대로 쓴다. 결과가 맞지 않으면 프롬프트 수정도 Claude가 한다. 원장님은 결과를 고르고 필요한 부분을 손으로 고친다. 생성은 제작 준비 단계에서 하고, 렌더 파이프라인(`03_Pipeline/`)은 이미지 생성 서비스를 호출하지 않는다.

| 도구 | 쓰는 경우 | 과금 | 조건 |
|---|---|---|---|
| codex CLI 0.160 내장 이미지 도구(`$imagegen`, gpt-image-2) | 기본 | ChatGPT 구독 사용 한도 안 | ChatGPT 로그인 상태의 내장 도구만 쓴다. API 키가 필요한 스크립트 경로(`image_gen.py` 등)로 넘어가지 않는다. 한도를 넘겨 크레딧을 사야 하면 원장님 승인 |
| Antigravity CLI `agy` 1.2.7(Nano Banana 계열) | codex의 기술 장애나, Claude가 프롬프트를 두 번 고쳐도 품질이 맞지 않을 때 | Google 계정 주간 한도 안 | 아래 사용 전 확인을 마친 뒤에만 쓴다. 같은 프롬프트를 그대로 쓴다 |

안전·권리·개인정보를 이유로 한 거부는 차선 도구로 넘기지 않는다. Claude가 거부 원인을 보고 6절 기준에 맞게 요청 자체를 고친 뒤 같은 도구에서 다시 시도한다.

#### 자산은 영상 작업 전에 전부 만든다

소품 없이 영상을 돌렸다가 다시 생성하는 일이 잦았다(원장님 경험). 처음부터 다 만들어 두는 편이 재생성을 줄이고 크레딧을 아낀다. 그래서 에피소드마다 다음 순서를 지킨다.

1. Claude가 `episode_card.md`와 대본을 바탕으로 `04_Episodes/EPxx_<slug>/storyboard.md`를 쓴다. 컷마다 컷ID, 길이, 카메라(가로·세로), 앵글, 캐릭터 동작, 배경ID, 등장 소품을 적는다.
2. 스토리보드에서 자산 목록을 뽑는다. 배경은 세트×앵글(정면, 반대편 등 컷에 나오는 방향마다 한 장), 소품은 하나씩 따로, 크기·색·열림처럼 상태가 바뀌는 소품은 상태마다 한 장이다. 목록에는 자산마다 프롬프트를 붙인다.
3. 이미 만든 자산(트리하우스 HQ, 마을 광장의 앵글, 반복 소품)은 다시 만들지 않고 재사용한다.
4. 목록의 자산을 전부 생성하고 원장님이 고른다.
5. 목록의 모든 자산이 `02_Assets/`에 들어온 뒤에 음성 배치와 Remotion 조립을 시작한다. 빠진 자산이 있으면 영상 작업에 들어가지 않는다.

프롬프트 규칙:

- `01_Bible/image_style.md`의 고정 스타일 문단(그림체, 색 팔레트, 선 굵기, 금지 사항)에 자산별 설명을 붙인다. 같은 세트의 앵글끼리는 같은 문단과 같은 참고 이미지를 쓴다. 참고 이미지로는 우리 자산과 SVG 렌더만 넣는다.
- 소품은 한 장에 하나, 단색 또는 투명 배경으로 만들어 바로 오려 쓸 수 있게 한다.
- 기존 작품·캐릭터·브랜드 이름과 "like <작품>" 지시를 쓰지 않는다. 실존 인물, 아이 사진, 학생 자료는 넣지 않는다.
- 이미지 안에 글자를 넣지 않는다. 학습 단어와 자막은 Remotion에서 정확한 철자로 얹는다.
- 사실적인 사진풍은 만들지 않는다. 6절 안전 기준을 프롬프트 단계에서 지킨다.
- 배경은 가로·세로 두 카메라가 모두 쓸 수 있게 화면보다 넉넉하게 만들고, 컷의 목표 사물과 행동이 두 화면비 모두에서 보이는지 스토리보드에서 확인한다.

#### 실행과 기록

Claude가 원장님 Mac에서 codex CLI를 자산 하나에 한 번씩 실행한다. 실행 지시에는 "아래 프롬프트를 바꾸지 말고 그대로 이미지 도구에 넘길 것"을 적고, codex 세션 기록에서 실제로 넘어간 프롬프트가 원문과 같은지 확인한다. 결과는 `02_Assets/_raw/<자산ID>_v<번호>_<도구>.png`로 옮겨 재생성 이력을 남긴다. 원장님이 고른 버전만 `02_Assets/`의 배경·소품 폴더로 간다. Remotion은 PNG를 그대로 쓸 수 있으므로, 벡터화(VTracer → Inkscape)는 움직이거나 색을 바꿔야 하는 자산에만 한다.

`05_Ops/assets_log.csv`에는 자산ID, 버전, 프롬프트(또는 프롬프트가 적힌 `storyboard.md` 위치), 도구, 모델, 구독 플랜, 생성일, 채택 여부, 사람의 수정 내역, 약관 근거와 확인일을 적는다. `_raw/`는 git에 넣지 않고 7절 백업 대상에 포함한다.

권리: OpenAI 약관은 산출물 소유권을 이용자에게 넘긴다. 이 조항은 서비스와의 관계일 뿐이고, 저작권 보호는 4절대로 사람의 창작 기여에 따라 따로 판단한다. OpenAI 도움말은 ChatGPT·Codex·API 생성 이미지에 C2PA 메타데이터와 SynthID 워터마크가 들어간다고 하지만, 제품·파일 형식·시기에 따라 다를 수 있다고 적는다. 원본 PNG를 `_raw/`에 그대로 두어 이 정보를 보존한다.

`agy` 사용 전 확인: Antigravity 문서는 이미지 도구를 Agent가 스스로 판단해 쓰는 기능으로 설명하고, CLI에서 직접 부를 수 있는지, 저장 위치와 이미지 한도는 밝히지 않는다. Antigravity 추가 약관과 Google 생성형 AI 약관의 산출물 소유·상업 이용 조항과 18세 미만 관련 조항도 아직 읽지 않았다. 이 항목을 확인하고, 시험 이미지에 눈에 보이는 워터마크가 없는지 본 뒤에 쓴다. `--dangerously-skip-permissions`는 쓰지 않는다.

1단계에서 실제 15초 테스트 영상에 쓸 배경(앵글 2장)과 소품 전부를 이 순서로 만들어, 가로·세로 렌더에서 목표 사물·행동·자막이 보이는지 확인하고 걸린 시간을 5절 제작 시간 기록에 넣는다.

AI 영상 생성 모델(Veo, Sora, Kling 등)은 주력으로 쓰지 않는다. 캐릭터 일관성과 대사 타이밍을 프레임 단위로 맞추기 어렵다. 배경 움직임 같은 보조 컷에만 시험한다. Moho·Cartoon Animator는 유료이고 GUI 수작업이 많아 제외했다.

코드 기반이라고 YouTube Kids의 AI 콘텐츠 제한을 피할 수 있다는 근거는 없다. 일반 YouTube 공개, 수익화 심사, YouTube Kids 앱 편입은 각각 다른 목표로 두고, Kids 앱 편입은 기대하지 않는다.

장면 프리셋을 재사용해 단어만 바꿔 찍어내면 '진정성 없는 콘텐츠'에 해당한다. 편마다 학습 목표, 갈등, 해결 방식, 시각적 설명을 `episode_card.md`에 적고, 앞 편들과 겹치는지 확인한 뒤 제작에 들어간다.

목표 제작 시간은 본편 8~10시간, 쇼츠 1~2시간으로 잡았지만 근거 없는 추정이다. 대본 수정, 음성 재생성, 새 소품, 썸네일, 메타데이터, 업로드, 권리 기록, 도구 유지보수 시간을 따로 기록해 3단계에서 판정한다.

주간 가용 시간(30~50시간)이 목표 제작 시간보다 넉넉하다. 남는 시간은 파이프라인 개선과 비축분 확대에 쓰고, 발행량을 늘릴지는 공개 8주차 리뷰에서 정한다.

## 6. 매 편 점검 항목

- 아동용(Made for Kids)으로 설정.
- `episode_card.md`의 학습 목표·갈등·해결·시각 설명이 이전 편과 다른가.
- 워치를 쓰는 편에서, 해결 장면의 명령문 뜻과 결과가 일치하는가. 워치를 쓰지 않는 편은 핵심 표현의 뜻이 캐릭터 행동과 화면으로 보이는가.
- 벌칙이 발음 실수가 아닌 '뜻이 다른 단어 선택'에만 걸렸는가.
- 제목·썸네일이 실제로 가르치는 문장과 같은가. 인기 키워드를 나열하지 않았는가.
- 아이가 따라 하면 위험한 행동(콘센트, 높은 곳, 약 등)이 없는가. 긴장 장면이 호기심 수준인가.
- 카드·엔드스크린을 전제로 한 대사("Click the next video" 등)가 없는가.
- 초당 3회를 넘는 번쩍임, 과한 화면 흔들림, 갑작스러운 큰 소리가 없는가.
- 모바일과 TV 화면에서 처음부터 끝까지 한 번 시청했는가. 자막·대사·배치가 잘리지 않는가.
- 업로드할 때 'AI 사용' 표기 대상인지 판단했는가. 만화처럼 사실적이지 않은 콘텐츠는 대상이 아니다. 사실적인 합성 장면이나 AI 음악이 중심인 영상(예: AI로 만든 노래 쇼츠)은 표기한다. 유튜브가 라벨을 자동으로 붙이면 기준에 맞는 라벨은 그대로 둔다.

## 7. 운영·보안 기준

- 채널: 기본 설정을 아동용으로, 2단계 인증과 복구 수단 등록, 업로드 전 비공개 상태로 검수.
- 권리 기록: `05_Ops/assets_log.csv`에 자산별 파일명, 도구, 플랜, 모델, 생성일, 라이선스, 사람의 수정 내역.
- 백업: 대본, 벡터 원본, 음성 원본, 이미지 생성 원본(`02_Assets/_raw/`), 최종 렌더를 서로 다른 두 곳에 보관. git에서 제외한 파일은 백업이 아니다.
- 비밀정보: API 키는 `.env`(저장소 제외)에만, 사용량 한도 설정, 로그에 키를 남기지 않는다. 음성 원본과 학생 관련 자료는 저장소에 넣지 않는다.
- 코드: `script.yaml`은 스키마로 검증하고 안전한 파서로 읽는다. 대본 문자열을 셸 명령이나 실행 코드에 그대로 넣지 않는다.

## 9. 수익화 전제

2027-02-01부터 신규 YPP 광고·Premium 수익 진입 기준은 구독자 1,000명과 함께 시청 8,000시간(365일) 또는 쇼츠 2,000만 회(90일)다. 쇼츠 피드 시청 시간은 시청 시간 기준에 들어가지 않는다. 가입 후에도 쇼츠 수익 배분은 90일 1,000만 회 이상일 때만 받는다.

기간은 주 30~50시간 기준 추정이다. 단계가 늦어지면 날짜를 미루고 조건은 그대로 둔다.

공개일은 날짜보다 3단계 조건에 묶는다. 아동용 채널은 구독자 알림이 없어 꾸준한 업로드에 기대야 하므로, 4주 분량을 쌓고 시작한다.

조건을 통과하지 못하면 범위를 줄인다. 1단계에서 막히면 동작을 '정지 포즈 + 입·눈만 움직임'으로 낮춰 다시 시험한다. 3단계 주간 작업 시간이 30시간을 넘으면 본편 길이와 장면 수를 줄이거나 본편을 격주로 바꾼다. 격주로 바꿔도 주 3회 업로드는 유지한다. 본편이 있는 주는 본편 1 + 쇼츠 2, 없는 주는 쇼츠 3이다. 합본 제작 시간도 해당 주의 작업 시간에 넣어 계산한다.

## 12. 시청 테스트 절차

- 대상: 학원 저학년(초1~2, 7~8세). 가능하면 보호자 동의를 받은 5~6세 아이를 더한다. 7~8세 결과만으로 5~7세 전체를 검증했다고 보지 않는다.
- 보호자 안내: 상업 유튜브 채널 개발을 위한 시청 테스트임을 알리고 동의를 받는다. 참여하지 않아도 수업·평가에 영향이 없다고 밝힌다. 아이도 언제든 그만둘 수 있다.
- 진행: 영상을 한 번 보여준 뒤 교사 힌트 없이 확인한다. 영상에 나오지 않은 새 물건 그림으로 "Make it small!"의 뜻을 고르게 해 전이를 보고, 다음 수업일에 같은 문항으로 유지를 본다.
- 기록: 개인별 기록 없이 집계 숫자만 남긴다(예: 8명 중 6명). 학생 이름, 얼굴, 목소리, 답변 원문은 저장하지 않고 AI 서비스나 저장소에도 올리지 않는다.
- 범위: 오프라인 익명 관찰만 한다. 웹 퀴즈나 음성 제출처럼 온라인으로 아이 정보를 받는 기능은 COPPA와 개인정보 보호법(만 14세 미만 법정대리인 동의)을 따로 검토하기 전에는 만들지 않는다.

## 13. 공개 후 측정

매주 편당 실제 제작 시간, 쇼츠의 '스와이프하지 않고 본 비율', 본편 평균 시청 지속률, 트래픽 소스(추천·탐색·검색·재생목록), 쇼츠 → 본편 유입, 재방문 시청자, 시청 국가를 기록한다. Gemini 자료의 목표 수치는 쓰지 않고 첫 8주 데이터를 기준선으로 삼는다.

8주차 리뷰의 판단 규칙:

- 주간 작업 시간(합본 포함)이 30시간을 넘는 주가 이어지면 본편 길이·장면 수 축소, 그래도 넘으면 본편 격주화(본편 없는 주는 쇼츠 3편).
- 시청 국가 상위권에 맞춰 메타데이터 번역 언어를 정한다(영어·한국어 + 2~3개 언어에서 시작).
- 시청 반응이 예상과 다르면 시즌 2 트랙(8~10세)을 앞당길지 검토한다.
