# Gemini 리서치 자료 검토

작성: Claude · 2026-10-19 · 대상: 저장소 Markdown 21개(README 2개 포함)

아이디어는 쓸 만하다. "영어 단어를 말하면 화면 속 사물이 그 뜻대로 바뀐다"는 장치, 침착한 리더와 사고뭉치 조수의 대비, 로고 없이 사건으로 여는 오프닝, 한 편 안에서 핵심 문장을 8~10번 모양을 바꿔 반복하는 구조는 시즌 1의 뼈대로 가져간다.

제작 계획은 대부분 다시 써야 한다. 유료 툴과 여러 명의 인력을 전제한 일정이 1인 제작 조건과 맞지 않는다. 수치에는 출처와 기준일이 적혀 있지 않다. EP01 대본은 서로 다른 버전이 섞여 있고, 유튜브 '아동용(Made for Kids)' 기능 제약과 2026년 정책 변화가 빠져 있다.

## 2. 고쳐야 할 문제

### 2.1 출처가 적히지 않은 수치

유튜브 통계("로고 인트로가 30~45% 이탈을 만든다", "아동용 채널 조회수의 80% 이상이 추천에서 온다", "CTR 7~12%", "쇼츠 평균 시청률 120~150%")는 원장님 확인 결과 Gemini 최신 모델로 조사한 자료로 신뢰도가 높다. 문서에 출처 링크와 기준일이 없으므로, 외부에 인용할 때는 원 출처와 기준일을 알면 함께 적고 모르면 Gemini 리서치에서 가져온 수치임을 밝힌다. 계획에서는 초기 기준값으로 쓰고, 공개 후 우리 채널 데이터로 갱신한다.

유튜브 통계가 아닌 수치는 따로 다룬다. "Krashen의 i+1 가설상 시각 맥락이 의미의 85%를 담당"은 원 가설에 없는 수치라 뺀다. 12px 글로우, 배경 25% 어둡게, 눈 20% 확대는 연구 결과로 적혀 있지만 디자인 기본값으로 쓴다.

### 2.2 벤치마크 구독자 수의 기준일

원장님 확인 결과 신뢰할 수 있는 조사 자료다. 두 채널을 표본으로 현재 값과 대조해 보니 표보다 30~35% 많았다(English Singsing: 표 ~4.2M+ → 2026-10 약 568만, Peekaboo Kidz: 표 ~5.8M+ → 2026-10 약 787만). 표의 '+'가 하한 표기이고 채널 간 규모 비교에는 문제가 없다. 표에 조사 기준일만 적어 둔다.

### 2.3 나이와 영어 수준을 한 축으로 묶음

문장 길이와 말 속도를 나이(5~7세 / 8~10세)로 나눴지만, 비영어권 8~10세 상당수는 영어 입문 단계다. 학습 설계는 영어 수준(CEFR Pre-A1 → A1)을 축으로, 연출과 유머는 나이를 축으로 따로 잡는다.

### 2.4 두 트랙을 한 시즌에 섞음

EP1~5는 5~7세, EP6~10은 8~10세다. 시청자 층이 편마다 바뀌면 추천 시스템이 채널의 시청자를 파악하기 어렵고, 캐릭터·세트·말투도 두 벌 필요하다. 시즌 1은 한 트랙으로 간다.

### 2.5 EP01 대본 버전 충돌과 논리 결함

EP01 폴더 5개 파일 중 `EP01_Master_Script_and_Storyboard.md`만 채널 바이블과 같은 줄거리(딸기 → 바나비 → 티라노 풍선이 커지고 "Make it small!"로 줄인다)다. 나머지 4개(`Master_Script_&_Audio_Plan`, `Second_by_Second`, `Cut_by_Cut_Storyboard`, `Voice_SFX_VFX_Directives`)는 '댄스 광선' 버전이다.

댄스 버전은 "Don't touch it!"을 세 번 외쳐서 버튼을 끈다. 말한 문장의 뜻과 결과가 이어지지 않아 채널의 핵심 장치를 스스로 깬다. 딸기 버전은 "Make it small!"이라고 말하면 실제로 작아지므로 장치와 맞는다. 딸기 버전을 기준으로 다시 쓰고, 댄스 버전에서는 타임코드 표·SFX 시트·컷 리스트 형식만 가져온다.

함께 고칠 것:

- 엔딩 대사 "Click the next video": 아동용 영상에는 카드와 엔드스크린이 없어 누를 대상이 없다. 삭제한다.
- '방사능 초록 발톱' 클리프행어: 4~5세에게 무섭다. 웃긴 발자국과 소리 정도의 호기심 장면으로 낮춘다.

### 2.6 입모양(바이짐) 설계 과잉과 불일치

12종 목록이 파일마다 다르다. `00_Character_Rigs...`는 MBP·AH·EE·OO_W·FV·TH·L·R·CH·SHOUT·SQUASH·CONFUSED, `AI_Character_and_12Viseme...`는 Closed·Open·Wide·Round·Pucker·Teeth·Tongue_L·TH·FV·Flare·Shout·Oops다. 캐릭터마다 12종을 그리고 핵심어마다 손으로 보정하는 방식은 1인이 주 3편을 만들 때 감당할 수 없다. 동물 주둥이 입모양을 보고 아이가 발음을 익힌다는 근거도 없다.

처리: 오픈소스 자동 립싱크 도구 Rhubarb Lip Sync의 입모양 체계(기본 6종 A~F, 선택 3종 G·H·X)를 쓴다. 기본 6종으로 시작하고 필요할 때 선택 3종을 더한다. TH와 F/V처럼 한국어에 없는 소리만 핵심어 장면에서 입 확대 컷으로 따로 보여준다.

### 2.7 낡은 도구 정보, 예산 원칙과 충돌

- Midjourney 프롬프트가 v6.1과 `--cref` 기준이다. 현재 기본 모델은 V8.2(2026-07)이고 `--cref`는 V7·V8에서 지원하지 않는다. Midjourney에는 무료 요금제가 없다.
- Moho Pro 14와 Cartoon Animator 5는 유료이고 GUI 수작업 비중이 커서 주 3편 1인 제작에 맞지 않는다.

처리: 이미 가입한 Gemini·ChatGPT 이미지 생성으로 시안을 만들고, 애니메이션은 코드 기반(Remotion)으로 바꾼다. 프롬프트 문서는 '캐릭터 외형 명세'로 줄여 남긴다.

### 2.8 아동용(Made for Kids) 기능 제약 미반영

아동용으로 설정한 영상은 댓글, 알림, 카드·엔드스크린, 미니플레이어, 재생목록·나중에 볼 동영상 저장, 맞춤형 광고, 채널 멤버십을 쓸 수 없다. 구독자에게 새 영상 알림이 가지 않으므로 시청자는 추천, 검색, 채널이 만든 시리즈 재생목록으로 들어온다(시청자의 '저장'이 막힐 뿐 제작자의 재생목록 구성은 가능하다). Studio 발췌 도구로 만든 쇼츠는 원본 영상이 관련 동영상으로 자동 연결되지만 아동용 쇼츠는 예외다. 쇼츠가 본편으로 시청자를 넘겨준다고 가정하면 안 된다. 맞춤형 광고가 꺼지므로 수익 기대치도 보수적으로 잡는다.

### 2.9 2026년 정책 변화 미반영

- 2025-07-15: 유튜브 파트너 프로그램(YPP)의 '반복 콘텐츠(repetitious content)' 규정 이름을 '진정성 없는 콘텐츠(inauthentic content)'로 바꿨다. 수익화 불가 예시에 "템플릿화된 줄거리", "대량 생산 인상을 주는 일반적·비독창적 템플릿의 AI 생성 콘텐츠", "영상 간 차이가 적고 교육적 가치가 낮은 콘텐츠"가 들어 있다.
- 2026-07-16: 같은 정책을 다시 설명하며 수익화 불가 유형을 셋으로 정리했다. 반복·범용 콘텐츠, 충격이나 감정 조종으로 조회수를 노리는 콘텐츠, 민감한 주제를 다루는 AI 인물 콘텐츠.
- 아동·가족 콘텐츠 품질 원칙: 따라가기 어려운 영상(대량 생산·자동 생성에서 흔함), 제목만 교육적인 영상, 인기 키워드를 반복하는 선정적 영상은 저품질로 분류되어 광고 제한이나 YPP 정지 사유가 된다.
- 2026-04: YouTube Kids 앱의 AI 생성 콘텐츠를 '소수의 고품질 채널'로 제한한다고 밝혔다.
- 2027-02-01: 신규 YPP 광고 수익 기준이 구독자 1,000명 + 시청 8,000시간(365일) 또는 쇼츠 2,000만 회(90일)로 오른다. 쇼츠 광고 수익 배분은 90일 1,000만 회 이상 채널에만 준다.

AI를 쓰는 것과 캐릭터·리그·문형을 재사용하는 것 자체는 문제가 아니다. 영상마다 학습 목표, 갈등, 해결 방식, 시각적 설명이 실제로 달라야 한다. 소품과 단어만 바꾼 '사고 → 실패 → 외침 → 해결' 반복은 위험하다. 제목과 썸네일은 실제 학습 내용과 맞아야 한다.

### 2.10 1인으로는 불가능한 주간 스프린트

5일 안에 4분 30초 본편, 쇼츠 3개, 60컷, 캐릭터 5~6명을 만드는 일정이다. 전통 2D 방식으로는 한 사람이 맞출 수 없다. 반복 작업을 코드로 자동화하는 파이프라인을 먼저 만든다.

### 2.11 캐릭터와 언어 범위 과다

등장인물 9명(토비, 모모, 코코, 폭시 렉스, 바나비, 레오, 미아, 피니, 시계 음성)과 메타데이터 10개 언어 번역을 첫 시즌부터 잡았다. 시즌 1은 토비·모모와 조연 1명, 메타데이터는 영어·한국어에 2~3개 언어를 더하는 정도로 시작한다.

### 2.12 이름 확인 필요

'BoomBoom'은 동요 'Chicka Chicka Boom Boom'을 비롯해 검색어가 겹치는 콘텐츠가 많다. 'Momo'는 2018~2019년 부모들 사이에 퍼졌던 'Momo 챌린지' 괴담과 이름이 같다. 둘 다 그것만으로 이름을 바꿀 이유는 아니다. 원장님 결정으로 채널명은 BoomBoom English, 캐릭터명은 토비·모모를 유지한다. 검색 혼잡과 법적 충돌은 별개이므로, 공개 전에 최종 영문·한글 표기와 변형(띄어쓰기, 발음), 로고를 KIPRIS와 WIPO Global Brand Database에서 주요 시장 기준으로 검색해 두기를 권한다.

캐릭터 프롬프트에 들어 있는 "like Sheriff Labrador and Bluey" 같은 기존 작품 모방 지시는 최종 외형 명세에서 뺀다.

### 2.13 중복 파일

`README.md`와 `README_KR.md`는 내용이 완전히 같다. 캐릭터 프롬프트 파일 3개가 서로 겹치고, SOP와 체크리스트도 같은 내용이다. EP01 파일 5개 중 4개는 같은 버전이다.
