# Weekly 5-Day Production Sprint SOP (1x 4.5m Episode + 3x Infinite-Loop Shorts)

## Day 1: Script & Master Audio-First Assembly
- [ ] Generate script using the **60:25:15 Ratio** and **Triple-Lock** markers (`[0.0s Pre-Cue]`, `[0.8s 0.5s-Pause + Keyword]`, `[1.8s Echo]`).
- [ ] Record single-creator expressive guide vocal track (exaggerated 1-octave prosody + 30% vowel elongation).
- [ ] Convert guide track via **ElevenLabs Speech-to-Speech (STS)** into Toby, Momo, Coco, Lex, and Narrator stems.
- [ ] Generate 25-second **120 BPM Word-Pop Chant** (Marimba/Xylophone/Ukulele stems).
- [ ] Assemble 4:30 Master Audio Timeline in Premiere/Audition, enforcing the **0.3s Clean Vocal Window** after every impact SFX.

## Day 2: AI Consistent Backgrounds & 3-Plane Layering
- [ ] Generate episode backgrounds using locked Wonder Paw Town `--sref` style seed.
- [ ] Separate PSD into 4 distinct layers: `01_Sky_Wall_BG`, `02_Midground_Stage`, `03_Target_Vocabulary_Objects`, `04_Foreground_Overlay`.

## Day 3 & Day 4: 2D Rig Animation (Moho Pro 14 / Cartoon Animator 5)

- [ ] **Manual 20% Polish:** Override lip-sync on all 8-10 Target English Keyword exposures using the **12 EFL Visemes** (`TH`, `F/V`, `W/R`, and `+20% Wide Shout Mouth`).
- [ ] Block body animation using the **50 Reusable Motion Clips**; add custom Squash & Stretch keyframes on Momo's slapstick moments.
- [ ] Keep all primary characters and target objects inside the **Center 9:16 Safe Guide** for instant Shorts extraction.

## Day 5: Pedagogical VFX, Sidechain Ducking & Multi-Format Export
- [ ] Apply After Effects/Premiere MOGRT presets: **12px Yellow Outline Glow + 25% BG Dimming**, **Karaoke Text Sync**, and **3s Quiz Timer**.

- [ ] Export `16:9 Master Episode (4:30)` + `3x 9:16 Seamless Loop Shorts (45s each)` + `High-CTR Thumbnail`.
